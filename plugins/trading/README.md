# Clawd trading skills

These Agent Skills are copied from the local go-bot skill library, including
support files (`references/`, `scripts/`, source). `skills/` and
`.agents/skills/` in that tree are the same folders via symlink, so each skill
is packed once. `swarm-orchestrator` is not duplicated here.

Bots discover them through `bundled_skill_list` / `bundled_skill_read` and the
desktop plugin-skills catalog. PayBox remains in `plugins/paybox`.
