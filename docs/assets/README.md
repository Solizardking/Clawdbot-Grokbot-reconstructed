# Clawd Bot documentation assets

- [`project-flow.svg`](project-flow.svg): animated Clawd Bot architecture overview
  (desktop workspace, inference, computers, tools, iOS companion); includes
  accessible text and honors reduced-motion preferences.
- [`git-map.svg`](git-map.svg): animated production source map of the parent
  reconstruction, `clawd/`, `clawd-mobile/`, docs, gateway, and GitHub workflows.
- [`router-settings.svg`](router-settings.svg): Clawd Bot routing illustration,
  not an application screenshot or a live availability indicator. Replaces the
  historical `router-settings.png` screenshot of the upstream application.

Both illustrations use editable SVG text with the existing violet documentation
palette. Product copy uses **Clawd Bot**. Provider names, runtime settings, and
upstream attribution retain their exact identities in the accompanying guides.
The application’s mascot sources remain in
[`clawd/public/brand/`](../../clawd/public/brand/README.md).
